#🎵 Vinilos App — Android (Jetpack Compose)

## 👨‍💻 Autor

**Estudiante:** Matthew Leyton

---

Aplicación móvil Android desarrollada en **Kotlin + Jetpack Compose**, que simula una tienda de vinilos musicales. La app integra **autenticación con Firebase**, **consumo de una API REST real** desplegada en **Render**, manejo de estado con **ViewModel + StateFlow**, persistencia ligera con **DataStore**, y **tests unitarios/UI**.

---

## 📱 Funcionalidades principales

* 🔐 **Autenticación de usuarios** (Login / Register) con Firebase Auth
* 🏠 **Pantalla Home** con acceso a productos y API
* 🎶 **Listado de productos (vinilos)** consumidos desde una API REST real
* 📄 **Detalle de producto** con información completa
* 🛒 **Carrito de compras** con cálculo de total
* 🌐 **Pantalla API** para:

  * Crear productos
  * Editar productos
  * Eliminar productos
* 🔄 Sincronización en tiempo real entre API y pantallas

---
